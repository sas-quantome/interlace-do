## Configuration Files

The following files are configurations for any project that uses the defined workflows.

- [sop.tsv](./sop.tsv): SOP (Standard Operating Procedure) table with WorkflowID, AppID, Code, Slot, and Filler columns.
- [work.tsv](./work.tsv): Work table with WorkflowID, Slot CV term, and Filler columns.
